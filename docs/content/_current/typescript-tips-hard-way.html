Most TypeScript pain comes from fighting the compiler instead of letting it change how you model data.

Turn on strict mode

strictNullChecks alone eliminates a whole class of runtime surprises. Endure a couple of days of red squiggles.

Model with unions

A request is loading, success or error — never all three. Discriminated unions make the compiler enforce your state machine.

Array footguns

  • Array.at(-1) returns T | undefined.
  • Never index with noUncheckedIndexedAccess off in real projects.

The goal is not fewer types — it is fewer production incidents.
