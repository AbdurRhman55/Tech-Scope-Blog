Large language models look like magic until you break them down. At its core, an LLM is a very large function that predicts the next token given everything before it.

1. Tokenization

Your text is split into tokens — word fragments, punctuation, whitespace markers. Each token maps to an integer ID from the model vocabulary.

2. Embeddings

Every token becomes a vector of numbers. These vectors encode meaning: similar concepts cluster together in vector space.

3. Attention

The transformer’s attention mechanism lets every token look at every other token and decide what matters. This is why context works.

Attention is all you need — and it is exactly what makes context windows possible.

4. Prediction

The model outputs a probability distribution over its vocabulary, samples one token, appends it, and repeats. That is autoregression.

Key takeaways

  • LLMs predict tokens, not truths.
  • Quality of output depends heavily on context and prompting.
  • Temperature controls randomness.

Understanding this pipeline makes prompt engineering far less mysterious: you are steering a probability machine, not talking to a person.
