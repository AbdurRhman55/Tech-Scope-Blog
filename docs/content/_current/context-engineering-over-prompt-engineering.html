Crafting the perfect sentence is a fragile strategy. The durable skill is arranging everything the model reads: documents, tools, history and constraints.

What counts as context

System policy, retrieved documents, conversation memory, tool schemas, even the order of examples. All of it shapes the output.

Design principles

  • Put constraints close to the task, not buried in a preamble.
  • Trim ruthlessly — irrelevant context degrades reasoning.
  • Structure beats prose: tables and lists are easier to follow.

Treat context like a workspace, not a scrapbook. Clean desks produce clean work.
