Clean code is not about cleverness; it is about the next developer — who is usually you, six months from now, with no memory of this.

Name things after intent

$data tells you nothing. $publishedPosts tells you everything. Names are documentation that cannot go stale.

Small functions, single jobs

If a function needs a comment to explain its steps, split it. Each function should do one thing and do it well.

Never trust input

Use PDO prepared statements for queries, escape output with htmlspecialchars(), and validate on the server — always.

$stmt = $pdo->prepare("SELECT * FROM posts WHERE slug = ?");$stmt->execute([$slug]);

Test the behaviour, not the implementation

Tests that break when you refactor without changing behaviour are slowing you down, not protecting you.

Maintainable code is a series of small, boring, disciplined decisions. That is the whole secret.
