Nobody reads a paper front to back. Researchers skim strategically, and so should you.

Pass 1 — the five-minute scan

Title, abstract, section headings, figures, conclusion. Decide if the paper is relevant at all.

Pass 2 — the hour

Read without proofs. Focus on claims, methods and whether the evidence supports the claims.

Pass 3 — the deep dive

Only for papers you will build on. Re-derive key results, check assumptions, note what you would do differently.

Reading everything deeply is not diligence — it is a recipe for never finishing.
