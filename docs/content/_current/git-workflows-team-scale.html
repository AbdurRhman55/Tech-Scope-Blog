Git does not get harder with a bigger team — long-lived branches do. The fix is shortening how long work stays unmerged.

Trunk-based, mostly

Small commits to main behind feature flags. Branches live hours, not weeks, so merges stay trivial.

Rules that prevent pain

  • Rebase your own branch freely; never rewrite shared history.
  • Require pull-request reviews but keep them small.
  • Tag releases from CI — never from a laptop.
