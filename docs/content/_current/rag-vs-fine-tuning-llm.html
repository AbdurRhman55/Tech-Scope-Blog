Teams reach for fine-tuning when they should be retrieving, and vice versa. The choice is less about hype and more about where your knowledge lives.

Retrieval-augmented generation

RAG keeps knowledge outside the model in a searchable index. You can update facts instantly, cite sources and keep the base model frozen.

Fine-tuning

Fine-tuning changes behaviour: tone, format, domain vocabulary. It is excellent for style and task patterns, poor at remembering fresh facts.

If the knowledge changes weekly, retrieve. If the behaviour never changes, fine-tune.

The practical default

  • Start with RAG + strong prompting.
  • Fine-tune only after prompt fatigue is measurable.
  • Budget for evaluation either way — you cannot improve what you do not measure.
