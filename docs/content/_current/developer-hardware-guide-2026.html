Spec sheets are marketing. Here is what changes daily comfort for people who build software.

Memory is the ceiling

Compilers, containers and browsers each want gigabytes. 16 GB is workable; 32 GB removes friction you stop noticing after a week.

CPU: single-core still rules

Most build tools and IDEs punish weak single-core speed more than they reward core count. Check generation before brand.

Do you need an NPU?

Only if you run local models daily. For everyone else it is a line item, not a reason.

Buy for the slowest thing you do every day, not the benchmark you run once.
