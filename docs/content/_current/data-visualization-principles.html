Data visualization is not decoration — it is compression. A good chart lets someone see in two seconds what a table hides in twenty minutes.

Start with the question

Before choosing a chart, write the single sentence you want the reader to take away. Every element must serve it.

Choose the form honestly

  • Comparison → bars
  • Change over time → lines
  • Correlation → scatter
  • Composition → stacked bars or treemaps

Remove everything else

Gridlines, borders, redundant labels and 3D effects add ink without information. Chartjunk is real.

If you have to explain the chart for a minute, the chart has failed.

Label directly, use color with intent, and let the data — not the palette — be the star.
