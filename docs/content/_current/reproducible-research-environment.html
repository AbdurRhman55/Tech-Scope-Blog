Irreproducible results are the quiet scandal of computational research. The fix is unglamorous plumbing.

Pin the environment

Lock dependency versions with a lockfile and record the interpreter version. Your laptop is not an environment specification.

Version the data

Hash raw inputs and store them somewhere immutable. Small tables can live in Git; large ones need DVC or object storage with versioning.

Make one command run it all

A single make reproduce or script that goes from raw data to figures. If rerunning takes more than three commands, nobody will do it.
